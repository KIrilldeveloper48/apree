# Apree

Локальное веб-приложение для управления задачами. Проект состоит из Next.js
клиента, NestJS API и PostgreSQL. Сейчас подготовлен технический каркас;
модель задач, миграции и UI доски будут добавляться следующими итерациями.

## Требования

- Node.js 22 или новее;
- npm 11 или новее;
- Docker Desktop с Docker Compose v2 — только для PostgreSQL.

Проверить версии можно командами:

```powershell
node --version
npm --version
docker compose version
```

## Локальный запуск

1. Установите зависимости:

   ```powershell
   npm install
   ```

2. Создайте локальный файл окружения из шаблона:

   ```powershell
   Copy-Item .env.example .env
   ```

   Пароль в шаблоне предназначен только для локальной разработки. Файл `.env`
   исключён из Git.

3. Поднимите PostgreSQL:

   ```powershell
   docker compose up -d db
   ```

4. В двух отдельных терминалах запустите API и web-клиент:

   ```powershell
   npm run dev:api
   ```

   ```powershell
   npm run dev:web
   ```

   В PowerShell с ограниченным выполнением сценариев используйте `npm.cmd`
   вместо `npm`.

## Ручная проверка текущего состояния

1. Выполните шаги локального запуска.
2. Убедитесь, что `docker compose ps` показывает сервис `db` в состоянии
   `healthy`.
3. В терминале API дождитесь сообщения NestJS об успешном старте. API слушает
   `http://localhost:3001`.
4. Откройте `http://localhost:3000` в браузере. Должна отображаться страница с
   текстом «Задачник Apree».

На этой стадии у API ещё нет маршрутов задач: ответ `404` на корневой URL
ожидаем. Подключение API к PostgreSQL, миграции и пользовательские сценарии
появятся в следующих вехах.

## Управление локальной БД

Остановить контейнер без удаления данных:

```powershell
docker compose down
```

Удалить контейнер и локальный том PostgreSQL:

```powershell
docker compose down --volumes
```

Вторая команда необратимо удаляет локальные данные БД.

## Переменные окружения

| Переменная                 | Назначение                                                             |
| -------------------------- | ---------------------------------------------------------------------- |
| `POSTGRES_DB`              | Имя локальной базы данных.                                             |
| `POSTGRES_USER`            | Пользователь PostgreSQL.                                               |
| `POSTGRES_PASSWORD`        | Пароль локального пользователя PostgreSQL.                             |
| `POSTGRES_PORT`            | Порт PostgreSQL на хосте.                                              |
| `DATABASE_URL`             | Строка подключения для будущего Prisma-клиента.                        |
| `API_PORT`                 | Зарезервированный порт API. Сейчас API использует `3001` по умолчанию. |
| `NEXT_PUBLIC_API_BASE_URL` | Зарезервированный публичный базовый URL API для web-клиента.           |

## Текущее состояние и ограничения

- Источником истины для задач станет PostgreSQL; localStorage не будет
  использоваться для постоянного хранения задач.
- Prisma, миграции, маршруты задач, Material UI и сама доска пока не добавлены.
- Авторизация, совместное редактирование, вложения и облачное развёртывание не
  входят в объём первой версии.
